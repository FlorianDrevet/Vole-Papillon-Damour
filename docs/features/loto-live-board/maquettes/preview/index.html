RG-01 : sorti / non sorti se lisent par la luminosité. 4 états lisibles en gris : non sorti (sombre), sorti (plein clair en A / plein encre en B), dernier (orange), voisin +1/−1 (case cerclée). RG-02/03 : chiffres grille 76 px, dernier numéro 320 px, Libre Franklin 800, chiffres tabulaires. RG-23 : grille = 75 % de la largeur, toute la hauteur. Pas de QR code ici (RG-21).
RG-22 : palette basculée en direct par la touche P ou le bouton de régie (voir E3). Les deux palettes sont deux jeux de variables CSS sur la même mise en page.
RG-04 : barre, curseur et témoin de saisie masqués après 3 s sans souris. La barre réapparaît au mouvement de la souris. Clavier : chiffres + Entrée = tirer · Retour arrière = annuler · L = ligne gagnée · B = bingo · Espace = pause / reprise · P = palette · F = plein écran. RG-05 : actions désactivées pendant l'envoi (bouton « en cours »). RG-06 : toast « Le numéro 42 est déjà sorti. »
RG-07 : annonce du numéro 2 s, remplacée par la saisie suivante. RG-08 : Pause après la ligne qui termine une partie « pause après », fermée par « Reprendre ». RG-09 : avant la 1re partie / après la dernière → ces écrans, jamais d'erreur. RG-21/24 : QR code uniquement Avant le début et Pause ; adresse courte volepapillondamour.fr/loto.
