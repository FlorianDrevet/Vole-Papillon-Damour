Ordre de lecture (RG-90, RG-91) : en-tête → accroche → encart bourse (date + horaires + adresse) AVANT les cartes → carte livre (RG-92) → non-réservation (RG-94) → bouton « Voir ma liste de recherche » (RG-95) → pied de message. La ligne « Boîte de réception » au-dessus du mail montre le texte d'aperçu (RG-96) : il n'apparaît pas dans le corps. Données d'exemple (livres, dates, adresse).
Contraintes mail : 600 px, une colonne, mise en page en tableaux et styles en ligne à l'implémentation. La règle de marque est faite de trois segments pleins (pas de dégradé, ignoré par Outlook). Titres Newsreader → repli Georgia ; texte Libre Franklin → repli Arial ; libellés IBM Plex Mono → repli Courier New. La couverture est une vraie <img> HTTPS, alt = titre du livre (RG-98).
RG-93 : un groupe par bourse et par mode, trié par date (le plus proche d'abord ; « Disponible dès maintenant » sans date en tête). Chaque groupe = encart + ses cartes. RG-90 : accroche au pluriel « 3 livres de votre liste vous attendent ». RG-94 : non-réservation au pluriel.
RG-97 : les livres rares vendus restent de simples lignes, dans une section « Livres rares suivis » placée après les cartes et avant la non-réservation. Pas de photo, pas de carte (hors périmètre). L'encart ici est en mode « Disponible dès maintenant » avec prochaine ouverture (RG-91).
E4 : sans couverture (bloc papillon, RG-92) · images bloquées (RG-98) · mode sombre (RG-98) · sans prénom · rares seuls (pas d'encart, pas de non-réservation, pas de bouton, RG-97) · version texte (RG-99) · disponible maintenant sans ouverture connue (RG-91).
