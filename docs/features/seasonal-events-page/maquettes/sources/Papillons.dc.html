A · Marque-page

Un vrai machaon : ailes supérieures en page imprimée bordée d'un liseré signet, ailes inférieures bleu ciel à queues, avec un œil orange.

B · Origami

Un papillon plié dans une page : facettes nettes, ombres franches, pointe orange. Le plus graphique, très lisible en petit.

C · Livre qui s'envole

Le livre lui-même devient papillon : deux pages pour ailes, la couverture dessous, le signet qui pend comme une queue.

D · Monarque relié

Silhouette de monarque orange cerclée d'encre ; les ailes inférieures sont rayées comme des dos de livres sur une étagère.
